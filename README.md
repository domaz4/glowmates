# Glow Mates (static + Supabase, no server)

1. supabase.com > New project (free).
2. SQL Editor > paste setup/setup.sql, replace PUT_ADMIN_PASSWORD_HERE with your admin password, Run.
3. Project Settings > API: copy Project URL + anon public key into config.js.
4. Upload this folder to GitHub, then host with Cloudflare Pages (or GitHub Pages) and point glowmates.beauty to it.
Admin = small "Admin" button in the footer.
